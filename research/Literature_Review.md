# Literature Review

All references below were checked against the Crossref metadata registry (author names, title, year, journal, volume, issue, pages, DOI). The verification log is in `Reference_Verification_Log.md`. Statements about each paper are limited to its well-established central findings; students should read the key papers themselves before the viva.

## 1. Working memory

Working memory is the limited-capacity system that temporarily holds and manipulates information in the service of ongoing cognition. Baddeley and Hitch (1974) replaced the idea of a unitary short-term store with a multi-component model comprising a **central executive** (attentional control) and two domain-specific slave systems: the **phonological loop** (verbal–acoustic material) and the **visuospatial sketchpad** (visual and spatial material). Baddeley (2000) later added the **episodic buffer**, a limited-capacity store that binds information across domains and with long-term memory. Baddeley (2012) reviews the evidence and the main controversies surrounding the model.

Alternative accounts emphasise **domain-general attention**. Cowan (2001) argued that the capacity of the focus of attention is about four chunks, and Barrouillet et al. (2004) showed in the *time-based resource-sharing* (TBRS) model that recall in complex-span tasks declines as the processing task captures attention for a larger proportion of the available time (higher cognitive load), irrespective of the content of the processing task. Oberauer et al. (2016) review competing explanations of capacity limits (decay, resource sharing, interference/binding) and conclude that interference between representations plays a central role.

## 2. Visuospatial working memory

Logie (1995) proposed that the visuospatial sketchpad contains a passive **visual cache** (form, colour) and an active **inner scribe** (spatial sequences/locations, rehearsal). Della Sala et al. (1999) developed the **pattern span** task, in which participants remember filled cells in matrices, and showed that memory for static visual patterns dissociates from memory for spatial sequences (Corsi span), supporting a visual/spatial fractionation. Klauer and Zhao (2004) reported double dissociations in dual-task experiments: spatial secondary tasks impaired spatial memory more than visual memory, and vice versa. Awh et al. (1998) showed that spatial working memory is rehearsed by covert shifts of spatial attention to the remembered locations, and that interfering with spatial attention during retention impairs spatial memory.

Visuospatial working memory is related to, but separable from, executive functioning; Miyake et al. (2001) used latent-variable analysis to show that spatial working-memory span tasks load heavily on executive control, whereas simpler short-term spatial storage tasks do so less. Shah and Miyake (1996) found that spatial span (with a spatial processing component) and verbal span predicted spatial ability and language comprehension respectively, supporting partly separable resources for spatial and verbal material.

The current task uses a **static spatial configuration** of filled cells in a 3×3 matrix, which is conceptually close to the pattern-span stimuli of Della Sala et al. (1999), presented briefly and tested by recognition.

## 3. Visual change detection

In the change-detection paradigm a memory array is followed by a blank retention interval and a test array; the participant reports whether anything changed. Phillips (1974) distinguished a high-capacity, short-lived sensory store from a durable, limited-capacity short-term visual memory using matrix patterns and same/different judgements. Pashler (1988) used change detection with letter arrays and proposed a formula to estimate the number of items held. Luck and Vogel (1997) showed that change-detection accuracy is high for arrays of up to about 3–4 items and declines with larger set sizes, and that objects with multiple features are stored as integrated objects. Rouder et al. (2011) explain how to estimate capacity (K) correctly: Pashler's formula is appropriate for whole-display probes, and Cowan's formula for single-item probes. Jiang et al. (2000) demonstrated that visual short-term memory encodes items in relation to the global **spatial configuration**: disrupting the configuration at test impairs change detection — directly relevant to SMIT, where the remembered unit is the configuration of filled cells.

Consolidation of an array into working memory is not instantaneous. Jolicœur and Dell'Acqua (1998) demonstrated a capacity-limited short-term consolidation stage, and Vogel et al. (2006) showed with masking that consolidating items into visual working memory takes measurable time (on the order of tens of milliseconds per item), so that masks or new inputs arriving shortly after offset can disrupt encoding. These findings correspond to the "working memory consolidation window" (200–500 ms) and the "change-detection target exposure" range in the lecture.

## 4. Complex span tasks

Complex span tasks interleave a **processing** task with **storage** of to-be-remembered items. Daneman and Carpenter (1980) introduced reading span (reading sentences while remembering final words) and showed that it predicts reading comprehension. Turner and Engle (1989) introduced operation span (verifying arithmetic equations while remembering words) and showed that span predicted comprehension irrespective of whether the processing task was reading or arithmetic. Unsworth et al. (2005) developed an automated operation span with an individually calibrated time limit for the math task and an accuracy criterion (85 %) for the processing component to ensure participants do not trade off processing for storage. Kane et al. (2004) introduced spatial complex spans including **symmetry span** — symmetry judgements on 8×8 matrices interleaved with memory for spatial locations — and found that verbal and spatial complex spans largely reflect a common domain-general executive-attention factor, although domain-specific storage variance also exists. Conway et al. (2005) provide a methodological review and user's guide for span tasks, including scoring and the importance of monitoring processing-task accuracy.

SMIT borrows two principles from complex span: (1) a processing task is performed between encoding and retrieval, and (2) processing accuracy is recorded to verify engagement. Unlike complex span, SMIT presents **one** pattern per trial, varies the **type** of processing task across conditions (including a no-processing control), and measures retrieval by **recognition** rather than serial recall.

## 5. Interference

Interference refers to the disruption of a target representation or response by competing information. In working memory, dual-task interference arises when a concurrent task competes for the same resources or representational space as the stored material. Logie et al. (1990) showed that visual short-term memory is selectively disrupted by visual secondary tasks (e.g., irrelevant pictures) more than by verbal tasks, and verbal memory by articulatory suppression. Cocchini et al. (2002) found that concurrent verbal and visual memory tasks produced little mutual interference, supporting domain-specific stores, whereas Morey and Cowan (2004) found that a verbal memory load impaired visual array change detection when the verbal load was large and articulated, suggesting a cross-domain (central) component. Conway and Engle (1994) linked working-memory capacity to the ability to resist interference during retrieval.

The literature therefore leads to two competing predictions for SMIT: a **domain-specific** account predicts larger disruption of spatial memory by the visual-spatial secondary task (H3), whereas a **domain-general attentional** account (Barrouillet et al., 2004) predicts that disruption depends mainly on how much attention each secondary task captures, regardless of content.

## 6. Selective attention

Selective attention allows relevant information to be prioritised and irrelevant information to be filtered. Posner and Petersen (1990) proposed three attentional networks — **alerting** (achieving and maintaining readiness), **orienting** (selecting locations) and **executive control** (resolving conflict) — and Fan et al. (2002) operationalised them in the Attention Network Test (ANT). In SMIT, the fixation cross engages alerting; the central fixed position of all stimuli limits the need for orienting; and conditions B and C require executive control to share attention between the secondary task and maintenance and to keep the orange distractor grid from being confused with the blue memory pattern.

## 7. Methodological literature used in the design

- **Speed–accuracy trade-off and IES.** Heitz (2014) reviews the speed–accuracy trade-off; Bruyer and Brysbaert (2011) show that IES is only appropriate when accuracy is high and error rates are similar across conditions.
- **Signal detection.** Stanislaw and Todorov (1999) give formulas for d′; Hautus (1995) recommends the log-linear correction for extreme proportions.
- **Effect sizes.** Lakens (2013) explains paired d_z and partial η² for repeated-measures designs; Kerby (2014) explains the rank-biserial correlation for nonparametric tests.
- **Repeated-measures ANOVA.** Mauchly (1940) test of sphericity; Greenhouse and Geisser (1959) correction.
- **Multiple comparisons.** Holm (1979) sequentially rejective procedure.
- **Power.** Faul et al. (2007) describe power analysis as implemented in G*Power; the same calculations are performed in Python with statsmodels.
- **Software timing.** de Leeuw (2015) describes jsPsych; Peirce et al. (2019) PsychoPy; Bridges et al. (2020) and Anwyl-Irvine et al. (2021) benchmark the timing precision of lab-based and browser-based experiment software and show that browser timing is generally adequate for RT experiments but varies across browsers and operating systems.
- **Age and processing speed.** Salthouse (1996) relates age-related cognitive differences to processing speed; relevant to the exploratory age analyses, though the expected student sample has a narrow age range.
- **Statistics software.** Vallat (2018) describes the Pingouin library.

## 8. Similar published experiments and SMIT's contribution

| Study | Memory task | Interference | Relation to SMIT |
|---|---|---|---|
| Logie et al. (1990) | Visual and verbal STM | Visual vs verbal secondary tasks | Same logic of selective (domain-specific) interference |
| Klauer & Zhao (2004) | Visual vs spatial STM | Visual vs spatial secondary tasks | Double dissociation logic; motivates H3 |
| Cocchini et al. (2002) | Verbal + visual memory concurrently | Memory load as interference | Domain-specific vs general debate |
| Morey & Cowan (2004) | Colour change detection | Verbal memory load | Change detection with cross-domain interference |
| Kane et al. (2004) | Spatial locations (symmetry span) | Symmetry judgement processing | Source of SMIT's visual secondary task |
| Turner & Engle (1989); Unsworth et al. (2005) | Words/letters | Arithmetic verification | Source of SMIT's numerical secondary task |

**What SMIT adapts.** SMIT combines (a) the brief-exposure, single-probe-display **change-detection** format with a matrix pattern (Phillips, 1974; Luck & Vogel, 1997; Della Sala et al., 1999), (b) the **processing-during-retention** principle and processing-accuracy monitoring of **complex span** tasks (Turner & Engle, 1989; Kane et al., 2004; Unsworth et al., 2005), and (c) a **within-subjects comparison of a numerical vs a visuospatial processing task against a no-load control** inspired by selective-interference studies (Logie et al., 1990; Klauer & Zhao, 2004).

**Claimed contribution (modest).** SMIT is a *custom experimental adaptation* — not a new psychological paradigm. Its distinctive features for a course project are: both secondary tasks are binary verification tasks matched in response format, timing window and true/false balance; the visual distractor is generated independently of the memory/probe patterns; recognition uses a single moved cell with a constant number of filled cells; and every phase is timed and logged against the display refresh rate. We are not aware of an identical published task, but a search of the literature cannot prove that one does not exist, so no originality claim is made beyond this adaptation.
