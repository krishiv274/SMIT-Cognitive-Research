Abstract

Objective. This study examined how numerical (arithmetic verification) and visual (spatial symmetry judgement) interference during the retention interval affect spatial working-memory recognition accuracy and reaction time in university students.

Method. In a within-subjects design, participants memorised four highlighted cells in a 3×3 grid (500 ms), performed no task (control), an arithmetic verification or a symmetry judgement during a 3,000 ms interference phase, and after a further 1,000 ms decided whether a probe grid was identical to the memorised pattern. Each participant completed 60 experimental trials (20 per condition) in a fully counterbalanced block order.

Introduction

Spatial working memory allows us to hold the layout of objects in mind for a few seconds — for example, remembering where items are on a map or a whiteboard while doing something else. Everyday life rarely allows undisturbed rehearsal: people calculate, read or look at other displays while trying to remember. Understanding whether different kinds of concurrent activity disrupt spatial memory equally, or whether disruption depends on overlap in content, informs theories of working memory (domain-specific versus domain-general resources) and has practical relevance for learning and multitasking.

This project adapts principles of the visual change-detection and complex-span paradigms into a single task, SMIT, in which a brief spatial pattern must be maintained across a delay that is empty, filled with arithmetic verification, or filled with a spatial symmetry judgement. Accuracy and reaction time of the delayed recognition decision are compared across conditions.

1. Working memory

Working memory is the limited-capacity system that temporarily holds and manipulates information in the service of ongoing cognition. Baddeley and Hitch (1974) replaced the idea of a unitary short-term store with a multi-component model comprising a central executive (attentional control) and two domain-specific slave systems: the phonological loop (verbal–acoustic material) and the visuospatial sketchpad (visual and spatial material). Baddeley (2000) later added the episodic buffer, a limited-capacity store that binds information across domains and with long-term memory. Baddeley (2012) reviews the evidence and the main controversies surrounding the model.

Alternative accounts emphasise domain-general attention. Cowan (2001) argued that the capacity of the focus of attention is about four chunks, and Barrouillet et al. (2004) showed in the time-based resource-sharing (TBRS) model that recall in complex-span tasks declines as the processing task captures attention for a larger proportion of the available time (higher cognitive load), irrespective of the content of the processing task. Oberauer et al. (2016) review competing explanations of capacity limits (decay, resource sharing, interference/binding) and conclude that interference between representations plays a central role.

2. Visuospatial working memory

Logie (1995) proposed that the visuospatial sketchpad contains a passive visual cache (form, colour) and an active inner scribe (spatial sequences/locations, rehearsal). Della Sala et al. (1999) developed the pattern span task, in which participants remember filled cells in matrices, and showed that memory for static visual patterns dissociates from memory for spatial sequences (Corsi span), supporting a visual/spatial fractionation. Klauer and Zhao (2004) reported double dissociations in dual-task experiments: spatial secondary tasks impaired spatial memory more than visual memory, and vice versa. Awh et al. (1998) showed that spatial working memory is rehearsed by covert shifts of spatial attention to the remembered locations, and that interfering with spatial attention during retention impairs spatial memory.

Visuospatial working memory is related to, but separable from, executive functioning; Miyake et al. (2001) used latent-variable analysis to show that spatial working-memory span tasks load heavily on executive control, whereas simpler short-term spatial storage tasks do so less. Shah and Miyake (1996) found that spatial span (with a spatial processing component) and verbal span predicted spatial ability and language comprehension respectively, supporting partly separable resources for spatial and verbal material.

The current task uses a static spatial configuration of filled cells in a 3×3 matrix, which is conceptually close to the pattern-span stimuli of Della Sala et al. (1999), presented briefly and tested by recognition.

3. Visual change detection

In the change-detection paradigm a memory array is followed by a blank retention interval and a test array; the participant reports whether anything changed. Phillips (1974) distinguished a high-capacity, short-lived sensory store from a durable, limited-capacity short-term visual memory using matrix patterns and same/different judgements. Pashler (1988) used change detection with letter arrays and proposed a formula to estimate the number of items held. Luck and Vogel (1997) showed that change-detection accuracy is high for arrays of up to about 3–4 items and declines with larger set sizes, and that objects with multiple features are stored as integrated objects. Rouder et al. (2011) explain how to estimate capacity (K) correctly: Pashler's formula is appropriate for whole-display probes, and Cowan's formula for single-item probes. Jiang et al. (2000) demonstrated that visual short-term memory encodes items in relation to the global spatial configuration: disrupting the configuration at test impairs change detection — directly relevant to SMIT, where the remembered unit is the configuration of filled cells.

Consolidation of an array into working memory is not instantaneous. Jolicœur and Dell'Acqua (1998) demonstrated a capacity-limited short-term consolidation stage, and Vogel et al. (2006) showed with masking that consolidating items into visual working memory takes measurable time (on the order of tens of milliseconds per item), so that masks or new inputs arriving shortly after offset can disrupt encoding. These findings correspond to the "working memory consolidation window" (200–500 ms) and the "change-detection target exposure" range in the lecture.

4. Complex span tasks

Complex span tasks interleave a processing task with storage of to-be-remembered items. Daneman and Carpenter (1980) introduced reading span (reading sentences while remembering final words) and showed that it predicts reading comprehension. Turner and Engle (1989) introduced operation span (verifying arithmetic equations while remembering words) and showed that span predicted comprehension irrespective of whether the processing task was reading or arithmetic. Unsworth et al. (2005) developed an automated operation span with an individually calibrated time limit for the math task and an accuracy criterion (85 %) for the processing component to ensure participants do not trade off processing for storage. Kane et al. (2004) introduced spatial complex spans including symmetry span — symmetry judgements on 8×8 matrices interleaved with memory for spatial locations — and found that verbal and spatial complex spans largely reflect a common domain-general executive-attention factor, although domain-specific storage variance also exists. Conway et al. (2005) provide a methodological review and user's guide for span tasks, including scoring and the importance of monitoring processing-task accuracy.

SMIT borrows two principles from complex span: (1) a processing task is performed between encoding and retrieval, and (2) processing accuracy is recorded to verify engagement. Unlike complex span, SMIT presents one pattern per trial, varies the type of processing task across conditions (including a no-processing control), and measures retrieval by recognition rather than serial recall.

5. Interference

Interference refers to the disruption of a target representation or response by competing information. In working memory, dual-task interference arises when a concurrent task competes for the same resources or representational space as the stored material. Logie et al. (1990) showed that visual short-term memory is selectively disrupted by visual secondary tasks (e.g., irrelevant pictures) more than by verbal tasks, and verbal memory by articulatory suppression. Cocchini et al. (2002) found that concurrent verbal and visual memory tasks produced little mutual interference, supporting domain-specific stores, whereas Morey and Cowan (2004) found that a verbal memory load impaired visual array change detection when the verbal load was large and articulated, suggesting a cross-domain (central) component. Conway and Engle (1994) linked working-memory capacity to the ability to resist interference during retrieval.

The literature therefore leads to two competing predictions for SMIT: a domain-specific account predicts larger disruption of spatial memory by the visual-spatial secondary task (H3), whereas a domain-general attentional account (Barrouillet et al., 2004) predicts that disruption depends mainly on how much attention each secondary task captures, regardless of content.

6. Selective attention

Selective attention allows relevant information to be prioritised and irrelevant information to be filtered. Posner and Petersen (1990) proposed three attentional networks — alerting (achieving and maintaining readiness), orienting (selecting locations) and executive control (resolving conflict) — and Fan et al. (2002) operationalised them in the Attention Network Test (ANT). In SMIT, the fixation cross engages alerting; the central fixed position of all stimuli limits the need for orienting; and conditions B and C require executive control to share attention between the secondary task and maintenance and to keep the orange distractor grid from being confused with the blue memory pattern.

What SMIT adapts. SMIT combines (a) the brief-exposure, single-probe-display change-detection format with a matrix pattern (Phillips, 1974; Luck & Vogel, 1997; Della Sala et al., 1999), (b) the processing-during-retention principle and processing-accuracy monitoring of complex span tasks (Turner & Engle, 1989; Kane et al., 2004; Unsworth et al., 2005), and (c) a within-subjects comparison of a numerical vs a visuospatial processing task against a no-load control inspired by selective-interference studies (Logie et al., 1990; Klauer & Zhao, 2004).

Claimed contribution (modest). SMIT is a custom experimental adaptation — not a new psychological paradigm. Its distinctive features for a course project are: both secondary tasks are binary verification tasks matched in response format, timing window and true/false balance; the visual distractor is generated independently of the memory/probe patterns; recognition uses a single moved cell with a constant number of filled cells; and every phase is timed and logged against the display refresh rate. We are not aware of an identical published task, but a search of the literature cannot prove that one does not exist, so no originality claim is made beyond this adaptation.

Theoretical Framework

1. The construct: visuospatial working memory

SMIT targets visuospatial working memory (VSWM): the temporary maintenance of the spatial layout of a small set of locations over a delay of a few seconds. In the multi-component model this corresponds to the visuospatial sketchpad (Baddeley & Hitch, 1974; Logie, 1995), supervised by the central executive. In embedded-process and resource-sharing accounts it corresponds to a limited set of items kept active by attention (Cowan, 2001; Barrouillet et al., 2004).

SMIT also involves — but does not isolate or clinically measure — selective attention (choosing the blue memory grid over orange distractors), executive control (coordinating storage and processing), interference management, encoding, maintenance and recognition. Performance in SMIT is a behavioural composite of these processes.

2. Source paradigms

2.1 Visual change detection (Phillips, 1974; Pashler, 1988; Luck & Vogel, 1997)

Principle borrowed: brief presentation of an array → blank delay → test array → same/different decision. Accuracy reflects how much of the array was stored; with a whole-display probe, capacity can be estimated with Pashler's K (Rouder et al., 2011).

How SMIT adapts it: the "items" are four filled cells in a 3×3 matrix (a pattern-span-like stimulus; Della Sala et al., 1999); a different probe moves exactly one filled cell so that the number of filled cells is constant and only the spatial configuration changes (Jiang et al., 2000). The delay is much longer (4 s instead of ≈ 1 s) and is filled with a secondary task in two conditions.

2.2 Complex span (Daneman & Carpenter, 1980; Turner & Engle, 1989; Kane et al., 2004)

Principle borrowed: storage is tested after an intervening processing task, and processing accuracy is monitored to prevent participants from neglecting it (Conway et al., 2005; Unsworth et al., 2005).

How SMIT adapts it: one storage episode per trial instead of a list; processing is a single verification problem; the type of processing is the experimental manipulation (arithmetic as in operation span; symmetry judgement as in symmetry span); a no-processing control is included.

2.3 Selective-interference (dual-task) paradigm (Logie et al., 1990; Klauer & Zhao, 2004)

Principle borrowed: if a secondary task disrupts memory more when it shares the memory's domain, the two rely on overlapping resources.

How SMIT adapts it: compares a numerical secondary task with a visuospatial one, against a control, within subjects.

Predicted mechanisms:

  1. Attentional capture (domain-general). Any secondary task reduces the time available for attentional refreshing of the pattern (Barrouillet et al., 2004) and for spatial rehearsal through covert attention shifts (Awh et al., 1998) → lower accuracy in B and C than in A (H1, H2).
  2. Domain-specific competition. The symmetry judgement requires building a representation of a second 3×3 spatial configuration in the same screen location. This competes with the sketchpad/inner-scribe resources and may overwrite or blend with the stored pattern (representational interference; Oberauer et al., 2016) → C < B (H3).
  3. Decision time. A degraded trace may require more evidence before a decision (slower RT) or lead to guessing (faster RT near the deadline). H4 is therefore non-directional.

5. Boundary conditions and construct-validity caveats

  • The two secondary tasks differ in content and possibly in difficulty; a difference between B and C could reflect difficulty rather than domain. Secondary-task accuracy and RT are therefore recorded and compared, and the interpretation of H3 must take any difficulty difference into account.
  • Condition A involves no response during the delay, so A–B and A–C differences combine cognitive load with motor/decision demands.
  • Because the probe re-presents the whole pattern, participants may use a holistic "gestalt" comparison rather than item-by-item memory; capacity (K) estimates should be interpreted cautiously.
  • The task measures recognition, not recall; recognition is generally easier and can be supported by familiarity.

Hypotheses

All tests are evaluated at α = .05 (two-sided), with Holm correction across the three pairwise comparisons for each dependent variable. A directional hypothesis is considered supported only if the corrected test is statistically significant and the effect is in the predicted direction.

Omnibus null hypothesis

  • H0 (omnibus): Interference type has no effect on spatial memory recognition performance. Formally, population mean recognition accuracy is equal across conditions A, B and C (μ_A = μ_B = μ_C), and likewise for mean correct recognition RT.
  • H0 alternative (omnibus): At least one condition mean differs from the others.

Theoretical rationale (summary)

  • H1 and H2 follow from resource-sharing and time-based accounts of working memory (Barrouillet et al., 2004) and from complex-span research showing that a processing task performed during retention reduces storage performance (Daneman & Carpenter, 1980; Turner & Engle, 1989; Conway et al., 2005). Any attention-demanding secondary task is expected to reduce the opportunity for attentional refreshing/rehearsal of the spatial pattern (Awh et al., 1998).
  • H3 follows from domain-specific (multi-component) models of working memory, in which a visuospatial secondary task competes for the same visuospatial resources as the stored pattern, whereas arithmetic draws more heavily on verbal/central resources (Baddeley & Hitch, 1974; Logie, 1995; Shah & Miyake, 1996; Klauer & Zhao, 2004). Note that domain-general accounts (e.g., Morey & Cowan, 2004; Cocchini et al., 2002 found evidence for both) would predict smaller or no differences between B and C if the two tasks are equally demanding — which is why secondary-task difficulty is measured.
  • H4 is non-directional because interference may slow recognition (weaker memory trace → longer decision time) or speed it (lower confidence → faster guessing near the deadline). The speed–accuracy trade-off is therefore examined explicitly.

Exploratory analyses (RQ2) — no confirmatory hypotheses

  • Correlations: age vs overall accuracy; age vs overall mean correct RT; age vs interference costs; accuracy vs RT (across participants).
  • Group comparisons by gender and academic course, only where each group has at least 5 participants (configurable); otherwise descriptive statistics only.
  • Order/fatigue: accuracy and RT by block position (1st, 2nd, 3rd) and trial number.

Interpretation rules (pre-specified)

  1. A non-significant result is reported as "no statistically significant evidence of a difference", never as evidence that no effect exists.
  2. Effect sizes (paired Cohen's d_z, partial η², rank-biserial r, Kendall's W) and 95% confidence intervals are always reported with p-values.
  3. Correlations are interpreted as associations only, never as causal effects.
  4. With N ≈ 20, a two-sided paired t-test has 80% power only for effects of d_z ≥ 0.66 at α = .05 (d_z ≥ 0.78 at the Holm-adjusted α = .0167 for the smallest p-value). Smaller true effects may not be detected.

Procedure and counterbalancing

After consent and registration, participants read illustrated instructions and completed 6 practice trials with feedback (repeatable up to 2 times), followed by three blocks of 20 trials (no feedback) separated by breaks of at least 20 s. Within each block, same and different trials were balanced (10 each) and randomly ordered with at most 3 consecutive identical answers. No memory pattern was repeated within a session. Block order was assigned with a persistent least-used rule over all six orders; each session's random seed and full trial plan were stored for reproducibility.

Mental model

To perform well the participant must hold the following internal rules (the task's mental model, L5):

  1. "Only the blue grid has to be remembered; orange grids and equations are a separate job."
  2. "The second blue grid either is identical or has exactly one square moved — the number of squares never changes, so counting does not help."
  3. "During the middle phase I must answer the equation/symmetry question and keep the blue pattern in mind."
  4. "F always means same / true, J always means different / false."
  5. "I have about 2 seconds to answer; if I wait too long the trial is lost."

The lecture describes how an inaccurate mental model produces systematic errors (L11). In SMIT a plausible faulty model is "orange grids may be the pattern to compare against" — this is why the distractor uses a different colour and why practice gives explicit feedback. The model also supports simulation & prediction (expecting the probe after the delay) and action & remediation (feedback in practice allows the model to be adjusted, L4, L6).

6. Design threats and controls

Floor and ceiling effects (L23, L27)

Configurable levers: grid.highlight_count, timing.memory_stimulus_ms, timing.interference_ms, trials.change_type (recognition difficulty) and timing.recognition_deadline_ms. Pilot criteria (see Pilot Testing Protocol): control-condition accuracy should fall roughly between 70 % and 92 % for most pilot participants, and no condition should average near chance (50 %).

Order effects and fatigue (L23)

Complete counterbalancing of block order; standardised breaks; short session (≈ 15–20 min); exploratory analysis of performance by block position and trial number.

Speed–accuracy trade-off (L24, L28)

Accuracy and RT are analysed separately; a response deadline is enforced; Inverse Efficiency Score (IES = mean correct RT / proportion correct) is computed as a supplementary measure only when accuracy ≥ 60 % in every condition, because IES is unstable and misleading at low accuracy (Bruyer & Brysbaert, 2011).

Hardware and timing (L24, L26)

  • The browser's refresh rate is estimated at session start (median of ≈ 60 animation-frame intervals) and stored with the session.
  • Stimulus changes are synchronised to requestAnimationFrame; planned durations are converted to whole numbers of frames (e.g. 500 ms = 30 frames at 60 Hz). Non-integer multiples (e.g. 500 ms at 75 Hz = 37.5 frames) are rounded to the nearest frame and the actual duration is recorded.
  • For every phase the measured duration (frame timestamps) is stored alongside the planned duration; deviations beyond one frame + 5 ms for the memory stimulus mark the trial as technically invalid.
  • Window blur / tab hiding (focus loss) is detected and flagged per trial; browser background-tab throttling would otherwise distort timing.
  • Keyboard events use event.timeStamp (high-resolution, same clock as frame timestamps); auto-repeat events and keypresses outside the response window are ignored and counted.
  • Testing should use the same desktop/laptop, monitor and wired keyboard for all participants (Bluetooth keyboards add ≈ 15–50 ms latency, L24), in full-screen mode, with other applications closed.
  • Browser-based timing is not laboratory-grade; published benchmarks show typical browser timing variability of a few to tens of milliseconds depending on platform (Anwyl-Irvine et al., 2021; Bridges et al., 2020). The project therefore does not claim laboratory-grade precision, and between-condition comparisons rely on all conditions sharing the same hardware within participants.

Limitations

  • Sample size. With about 20 participants, a paired comparison has 80% power only for effects of d_z ≥ 0.66 (α = .05); smaller effects may go undetected and estimates are imprecise.
  • Convenience sampling. University students recruited through personal and class networks; results may not generalise.
  • Demographic imbalance. Gender and course groups are small and unequal, so demographic comparisons are exploratory and often descriptive only.
  • Restricted age range. A narrow student age range limits age-related conclusions.
  • Browser and hardware timing. Browser timing is not laboratory-grade; mitigated by frame-synchronised presentation, measured durations, a single testing computer and a wired keyboard.
  • Secondary-task difficulty differences. Arithmetic and symmetry tasks may differ in difficulty and attentional demand.
  • Construct validity. Recognition with a whole-display probe may rely on holistic familiarity; the task does not isolate visuospatial storage from executive control; the control condition has no secondary response.
  • Practice effects and fatigue. Mitigated by counterbalancing and breaks but not eliminated.
  • Generalisability. A single set size, grid and timing configuration; effects may differ with other parameters.

Your task: remember where the blue squares are

  1. Look at the cross (+) in the middle of the screen. A grid will appear shortly.
  2. Memorise the pattern. A 3×3 grid appears for half a second. Four squares are blue. Remember where they are.
  3. Middle phase (3 seconds). Depending on the block, one of three things happens:
  4. Hold: the screen is empty — just keep the blue pattern in mind.
  5. Equation: a sum like 7 + 6 = 13 appears. Decide if it is correct. F = True, J = False.
  6. Symmetry: a different grid with orange squares appears. Decide whether the orange pattern is symmetrical (the left side is a mirror image of the right side). F = Yes (symmetrical), J = No. The orange grid is not the pattern you need to remember — keep remembering the blue one.
  7. Wait for one more second.
  8. Compare. A second blue grid appears. Is it exactly the same as the first blue pattern?
  9. Press F if it is the same.
  10. Press J if it is different. When it is different, exactly one blue square has moved to a new position. There are always four blue squares.
  11. You have 2 seconds to answer. Please respond as quickly and as accurately as you can.

Appendix F. Statistical methodology (Statistical Analysis Plan)

Status: Fixed before data collection. The numerical thresholds below are stored in the analysis section of the experiment configuration and are locked together with the configuration (version identifier recorded in every session). The analysis code in backend/app/analysis/ implements exactly this plan.

1. Units of analysis

  • The participant is the independent observational unit for all inferential tests. Trial-level data are aggregated to one value per participant per condition before testing. 1,200 trials from 20 participants are never treated as 1,200 independent observations.
  • Trial-level data are used for descriptive summaries, data-quality checks and learning/fatigue plots only.

2. Data sources and scope

  • Only main-study sessions are analysed. Pilot sessions (session_type = pilot) and practice trials (practice_trial = true) are excluded from all primary analyses.
  • Data collected by the application and data uploaded via the Excel/CSV templates enter the same pipeline.
  • Participant-summary-only imports (no trial-level data) contribute to participant-level analyses only; trial-level quality checks, timing checks, RT distributions, signal-detection measures and learning/fatigue analyses are unavailable for those participants and this is stated in the report.

3. Trial classification

4. Participant-level exclusion rules (pre-specified)

A participant is excluded from the confirmatory analyses if any of the following holds. Every exclusion is listed with its reason in the report.

  1. Withdrawn consent, or session not completed (fewer than the planned number of experimental trials recorded).
  2. Fewer than 15 of 20 technically valid trials in any condition.
  3. Timeout rate > 25 % across experimental trials (non-engagement).
  4. The same response key used on ≥ 90 % of answered recognition trials (non-engagement / response bias).
  5. Secondary-task accuracy < 60 % in condition B or C (failure to engage with the interference manipulation, adapted from the processing-accuracy criterion used in complex-span research; Unsworth et al., 2005, used 85 %, which we relax because our secondary task is short and timed).
  6. Excluded by the researcher with a documented reason (e.g., participant reported not understanding the task, severe interruption, equipment failure).

Not an exclusion criterion: low recognition accuracy. Poor performers who engaged with the task are retained, because excluding them on the basis of the primary outcome would bias the results.

Interference costs (sign convention)

Costs are defined so that a positive value always means worse performance under interference:

  • Numerical accuracy cost = Accuracy_A − Accuracy_B
  • Visual accuracy cost = Accuracy_A − Accuracy_C
  • Numerical RT cost = RT_B − RT_A (ms)
  • Visual RT cost = RT_C − RT_A (ms)
  • Mean interference cost = mean of the numerical and visual costs (used in exploratory correlations)

6. Descriptive statistics

For each DV, overall and by condition: n, mean, SD, median, minimum, maximum, IQR, and 95 % CI of the mean (t-distribution). Trial counts, accuracy, error rate, timeout rate, mean and median correct RT are also reported at the trial level (descriptive only).

7. Confirmatory analyses (H0–H4)

Performed separately for accuracy (H1–H3) and mean correct RT (H4).

7.1 Assumption checks

  • Normality of each pairwise difference score (A−B, A−C, B−C): Shapiro–Wilk (α = .05) and Q–Q inspection.
  • Sphericity: Mauchly's test; Greenhouse–Geisser ε is always reported.
  • Ceiling check: proportion of participants at 100 % accuracy in each condition.

7.2 Omnibus test

  • Parametric route (chosen if no difference score violates normality at α = .05): one-way repeated-measures ANOVA, F, df, p, partial η². If Mauchly's test is significant (p < .05), Greenhouse–Geisser-corrected df and p are reported as the primary result.
  • Nonparametric route (chosen if any difference score violates normality, or if > 25 % of participants are at ceiling in any condition): Friedman test with Kendall's W.
  • The test not chosen is still reported as a sensitivity analysis. The reason for the choice is printed in the results.

7.3 Pairwise comparisons

Three comparisons per DV: A vs B (H1), A vs C (H2), B vs C (H3 / H4 follow-up).

  • Paired t-test (two-sided) with mean difference, 95 % CI, t, df, p, Cohen's d_z = mean difference / SD of differences, and Hedges-corrected g_z.
  • Wilcoxon signed-rank test (two-sided) with rank-biserial correlation r_rb (Kerby, 2014).
  • Holm correction across the three comparisons, separately for each DV and each test family. The primary test (t or Wilcoxon) follows the route chosen in 7.2.
  • Pairwise comparisons are interpreted regardless of the omnibus result, because H1–H3 are planned contrasts; the omnibus result is reported for context.

7.4 Hypothesis decisions

If a test is significant in the opposite direction, the hypothesis is reported as not supported (effect in the opposite direction). The report always states that a non-significant result does not demonstrate the absence of an effect.

7.5 Manipulation check

Secondary-task accuracy and RT in B vs C are compared with a paired t-test / Wilcoxon (same rules). A significant difference indicates the two interference tasks were not matched in difficulty, which must be discussed when interpreting H3.

7.6 Sensitivity analyses

  • Accuracy computed on answered trials only.
  • Primary analyses repeated including participants flagged by exclusion rules 3–5 (if any).
  • d′ analysed with the same omnibus/pairwise procedure (exploratory).

8. Exploratory analyses (RQ2)

  • Correlations (participant level): age × overall accuracy; age × overall mean correct RT; age × mean accuracy cost; age × mean RT cost; overall accuracy × overall mean correct RT; plus a correlation matrix of numeric participant-level variables. Pearson's r is used when both variables pass Shapiro–Wilk (α = .05) and neither has fewer than 5 distinct values; otherwise Spearman's ρ. Reported: coefficient, 95 % CI (Fisher z; for ρ with the Bonett–Wright standard error), p, n. No multiplicity correction for exploratory correlations, which are labelled exploratory. Correlation ≠ causation.
  • Gender and course. Nominal variables are never numerically coded as continuous variables. Groups with fewer than 5 participants are reported descriptively only. Two groups: Welch's t-test with Hedges' g, plus Mann–Whitney U with rank-biserial r. Three or more groups: Welch's ANOVA (ω²/η²) and Kruskal–Wallis (ε²). "Prefer not to answer" and missing categories are excluded from inferential comparisons and reported descriptively.
  • Order and fatigue. Accuracy and RT by block position (1st/2nd/3rd) — Friedman/RM-ANOVA with the same rules — and accuracy/RT across trial number within blocks (descriptive plot).
  • Condition order. Descriptive comparison of performance across the six counterbalancing orders (groups too small for inference with N ≈ 20).

9. Power and sample size

With N = 20, a two-sided paired t-test at α = .05 has 80 % power for d_z ≥ 0.66; at the strictest Holm level (α = .0167) for d_z ≥ 0.78 (computed with statsmodels TTestPower). Detecting d_z = 0.5 with 80 % power would require ≈ 34 participants. The study is therefore powered only for medium-to-large effects; this is stated as a limitation.

10. Software

Python: pandas, NumPy, SciPy, statsmodels (power, multiple testing), Pingouin (cross-checks), Matplotlib (figures). Every analysis run stores the dataset hash, configuration versions, software versions, exclusion log and the full results JSON (analysis_runs table), so results can be reproduced.

11. Deviations

Any deviation from this plan after data collection (e.g., an unforeseen data problem) must be documented in the report's "Deviations from the analysis plan" section, with the reason and the result of the planned analysis alongside the deviating one.

Appendix G. Pilot-testing protocol

Purpose. Pilot testing checks that the task works for real people and calibrates difficulty before the configuration is locked (L23, L27). Software tests (pilot/Technical_Dry_Run_Report.md) are not human pilot testing and must never be reported as such.

Who. 3–5 volunteers similar to the target population (adult university students) who will not take part in the main study. Pilot data are stored with session_type = pilot and are excluded from all main analyses automatically.

Procedure

  1. In the researcher dashboard open Configuration, review the draft configuration and save any changes as a new draft version.
  2. Open Pilot Mode and click Start pilot session. The participant view opens in a new tab with a pilot banner (the banner is visible only to the researcher before the task starts; it is not shown during trials).
  3. Use the same computer, monitor, wired keyboard, room and lighting planned for the main study. Close other applications and disable notifications.
  4. Read the instructions aloud with the volunteer if needed and observe them silently during the task. Note anything confusing.
  5. After the session, ask the debrief questions in pilot/Human_Pilot_Testing_Checklist.xlsx (sheet Debrief).
  6. In Pilot Mode → Session details, inspect the timing table: planned vs measured durations, refresh-rate estimate, dropped-frame warnings and focus-loss flags.
  7. Record observations in the checklist and in the dashboard (Settings → Pilot observations), which feed the report's "Pilot testing" section.
